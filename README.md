# 🎲 스트림스 보드게임 (Streams Board Game)

**🌐 온라인 멀티플레이어 지원!** 인터넷을 통해 친구들과 실시간으로 플레이하세요!

## 게임 소개

스트림스는 숫자를 오름차순으로 배치하여 최고 점수를 획득하는 전략 게임입니다. 20칸의 시트지에 숫자를 배치하되, 오름차순을 유지하면서 긴 '스트림(덩어리)'을 만들어야 높은 점수를 얻을 수 있습니다.

### 🌐 온라인 멀티플레이어
- **방 생성/참가**: 간단한 방 코드로 친구 초대
- **실시간 동기화**: Socket.io 기반 실시간 게임
- **1-4인 지원**: 최대 4명까지 동시 플레이
- **대기실 시스템**: 게임 시작 전 준비 확인

## 게임 방법

### 온라인 멀티플레이어 게임 시작
1. **플레이어 이름 입력**: 자신의 이름을 입력합니다
2. **방 만들기 또는 참가하기**:
   - 방 만들기: 새로운 게임 방을 생성하고 방 코드를 받습니다
   - 방 참가하기: 친구가 만든 방의 코드를 입력하여 참가합니다
3. **대기실에서 준비**: 모든 플레이어가 "준비" 버튼을 클릭합니다
4. **게임 시작**: 방장이 "게임 시작" 버튼을 클릭하면 게임이 시작됩니다

### 게임 진행
1. **타일 뽑기** (방장만 가능): 방장이 "타일 뽑기" 버튼을 클릭
2. **타일 공개**: 모든 플레이어에게 같은 타일이 동시에 공개됩니다
3. **동시 배치**: 각 플레이어가 자신의 시트지에 타일을 배치합니다
   - 다른 플레이어의 배치가 실시간으로 보입니다
   - 모든 플레이어가 배치를 완료해야 다음 라운드로 진행
4. **라운드 반복**: 20라운드 동안 반복
5. **최종 결과**: 가장 높은 점수를 획득한 플레이어가 승리!

### 특별 규칙
- **같은 숫자**: 연속된 같은 숫자는 오름차순으로 인정됩니다
- **조커 타일 (⭐)**: 와일드카드로 작동하며, 항상 오름차순을 유지합니다
  - 조커는 어떤 숫자와도 오름차순을 이루는 것으로 간주됩니다
  - 조커를 활용하여 긴 스트림을 만들 수 있습니다
  - 예: [5, ⭐, 10] → 유효한 스트림 (조커가 자동으로 이어줌)
  - 예: [10, ⭐, 5] → 스트림 끊김 (5가 10보다 작음)
- **필수 배치**: 모든 칸을 반드시 채워야 게임이 유효합니다

## 점수 계산

각 스트림의 길이에 따라 점수가 계산됩니다:

| 스트림 길이 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|------------|---|---|---|---|---|---|---|---|
| 점수 | 1 | 3 | 6 | 10 | 15 | 21 | 28 | 36 |

**점수 공식**: `점수 = n × (n + 1) / 2` (n: 스트림 길이)

스트림이 길수록 점수가 기하급수적으로 증가하므로, 긴 스트림을 만드는 것이 승리의 핵심입니다!

## 게임 예시

### 예시 1: 기본 스트림
```
배치된 숫자: [5, 12, 15, 15, 20] [3, 8] [45, 67, 89, 99]
              ─────────────────    ─────   ───────────────
스트림 1: 5칸 (15점)              2칸 (3점)    4칸 (10점)

총 점수: 15 + 3 + 10 = 28점
```

### 예시 2: 조커 활용
```
배치된 숫자: [5, ⭐, 12, 15, ⭐, 20] [3, 8]
              ───────────────────────    ─────
스트림 1: 6칸 (21점)                   2칸 (3점)
         (조커가 스트림을 이어줌!)

총 점수: 21 + 3 = 24점
```

## 실행 방법

### 방법 1: 로컬 실행

#### 사전 요구사항
- Node.js (v14 이상)
- npm

#### 설치 및 실행
```bash
# 의존성 설치
npm install

# 서버 시작
npm start
```

서버가 시작되면 브라우저에서 `http://localhost:3000`에 접속하세요!

#### 개발 모드 (자동 재시작)
```bash
npm run dev
```

### 방법 2: Docker 배포 (권장)

#### 사전 요구사항
- Docker
- Docker Compose

#### Docker Compose로 실행 (가장 간단)
```bash
# 이미지 빌드 및 컨테이너 시작
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 중지
docker-compose down
```

#### Docker만 사용
```bash
# 이미지 빌드
docker build -t streams-boardgame .

# 컨테이너 실행
docker run -d -p 3000:3000 --name streams-game streams-boardgame

# 로그 확인
docker logs -f streams-game

# 중지 및 삭제
docker stop streams-game
docker rm streams-game
```

서버가 시작되면 브라우저에서 `http://localhost:3000`에 접속하세요!

### 배포 (프로덕션)

Docker Compose를 사용하여 클라우드 서버에 배포할 수 있습니다:

```bash
# 서버에 코드 복사
git clone <repository-url>
cd streams-boardgame

# Docker Compose로 백그라운드 실행
docker-compose up -d

# 업데이트 시
git pull
docker-compose down
docker-compose up -d --build
```

**포트 설정**: 기본 포트는 3000입니다. 변경하려면 `docker-compose.yml`의 포트 매핑을 수정하세요.

## 전략 팁

### 기본 전략
1. **처음엔 중간 값을 사용**: 낮은 숫자와 높은 숫자를 위한 공간을 확보하세요
2. **조커를 현명하게 활용**:
   - 조커는 어떤 숫자 사이에도 배치 가능한 만능 타일입니다
   - 끊길 뻔한 스트림을 이어주는 데 사용하세요
   - 조커를 너무 일찍 사용하지 마세요 - 나중에 더 유용할 수 있습니다
3. **여유 공간 확보**: 한쪽에 너무 많이 배치하면 나중에 배치할 곳이 없어집니다
4. **긴 스트림 우선**: 여러 개의 짧은 스트림보다 하나의 긴 스트림이 더 높은 점수를 줍니다
5. **조커의 위치 선택**: 조커는 불연속적인 숫자 사이에 배치하여 스트림을 연장하세요

### 온라인 멀티플레이어 전략
1. **상대방 관찰**: 다른 플레이어의 배치를 실시간으로 보며 전략을 조정하세요
2. **빠른 배치**: 동시 배치 시스템이므로 빠르게 결정하는 것도 중요합니다
3. **심리전**: 같은 타일을 받았을 때 누가 더 현명하게 배치하는지 겨루세요
4. **유연한 전략**: 다른 플레이어의 점수를 보며 공격적/수비적 전략을 선택하세요
5. **조커 타이밍**: 다른 플레이어가 조커를 어떻게 활용하는지 관찰하세요
